How it works

1

Add the workflow file

Copy a 10-line YAML config into .github/workflows/schema-diff.yml (or equivalent for GitLab, Jenkins, CircleCI, Bitbucket). No tokens, no signup, no infrastructure.

2

Diff runs on every PR

When a developer opens a PR with schema changes, SchemaLens compares the old and new schema, detects breaking changes, and generates a migration script.

3

Review with confidence

The diff report appears as a PR comment or Check Run. Reviewers see exactly what changed, the risk score, and the suggested migration — before merging.

Frequently asked questions

Can I try SchemaLens Team before buying?

Yes. Start with the free GitHub Action — it includes visual diffs and basic breaking-change detection. Upgrade to Team when you need shared workspaces, drift alerts, and admin controls.

Is there a limit on team members?

No. The Team plan covers everyone in your organization at one flat price. Add engineers, QA, DBAs, and managers without counting seats.

Does my data leave my infrastructure?

No. SchemaLens runs in your CI runner or browser. We never see your schemas. The Team dashboard uses shareable alert pages that you control and can keep private.

What CI/CD platforms are supported?

GitHub Actions, GitLab CI, Jenkins, CircleCI, and Bitbucket Pipelines. All platforms get smart skip, breaking-change detection, and migration generation.
