### Tagline

### Description
SchemaLens is a browser-based SQL schema diff and migration generation tool for PostgreSQL, MySQL, SQLite, SQL Server, and Oracle.

**Core Features:**
- Visual semantic diff (tables, columns, indexes, constraints, foreign keys)
- Automatic migration script generation (ALTER TABLE, CREATE INDEX, DROP, etc.)
- Breaking change detection with severity scoring
- 100% client-side — zero data transmission
- Free tier: 15 tables per comparison
- Pro: $39 lifetime — unlimited, exports, history

**Integrations:**
- GitHub Action for PR comments
- VS Code extension
- npm CLI (schemalens-cli)

**Also includes:** 51+ free SQL micro-tools (ORM converters, query generators, migration checkers, schema design interviews)
