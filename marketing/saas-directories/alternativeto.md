### Full Description
SchemaLens is a browser-based SQL schema diff tool for developers and DBAs. Paste two CREATE TABLE dumps, get a visual semantic diff showing added/removed tables, columns, indexes, and constraints — then copy the ready-to-run ALTER TABLE migration script in PostgreSQL, MySQL, SQLite, SQL Server, or Oracle.

**Key Features:**
- Visual schema diff (not line-by-line text diff)
- Migration script generation for 5 SQL dialects
- Breaking change detection with risk scoring
- GitHub Action for PR comments
- VS Code extension
- 51+ free micro-tools (SQL generators, ORM converters, query explainers)
- Free tier: up to 15 tables per comparison
- Pro: $39 lifetime — unlimited tables, full exports, history

**Privacy:** Entirely client-side. Your schemas never leave your browser.
