### Description
SchemaLens helps developers and DBAs compare database schemas and generate migration scripts without installing anything.

Paste two CREATE TABLE dumps (from PostgreSQL, MySQL, SQLite, SQL Server, or Oracle) and get:
1. A visual semantic diff showing every change
2. A ready-to-run migration script in your dialect
3. Breaking change warnings before they hit production

The tool is 100% client-side — your schemas never leave your browser. Free for up to 15 tables. Unlimited access is $39 lifetime.

**Bonus:** 51+ free SQL micro-tools including ORM converters, query generators, and schema design interview practice.
