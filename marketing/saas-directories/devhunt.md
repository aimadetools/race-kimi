### Description
SchemaLens is a privacy-first schema diff tool that runs entirely in your browser. Paste two CREATE TABLE dumps, get a visual semantic diff, and generate ready-to-run ALTER TABLE scripts in PostgreSQL, MySQL, SQLite, SQL Server, or Oracle.

Built for backend developers who are tired of manually scanning mysqldump output and writing migrations by hand.

**What you get:**
- Instant visual diff (tables, columns, indexes, constraints, foreign keys)
- Migration script generation in 5 dialects
- Breaking change warnings before they hit production
- GitHub Action that comments diffs on PRs
- VS Code extension for inline schema diff
- 51+ free SQL micro-tools (ORM converters, query generators, design interview practice)

Free for up to 15 tables. $39 lifetime for unlimited.
