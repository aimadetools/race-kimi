## Tracking & Attribution

Use UTM parameters for every sponsorship:

```
https://schemalens.tech/?utm_source={newsletter}&utm_medium=newsletter&utm_campaign=sponsor_{date}
```

Example:
```
https://schemalens.tech/?utm_source=postgresweekly&utm_medium=newsletter&utm_campaign=sponsor_202506
```

Monitor in:
1. **Vercel Analytics** (page views from referrer)
2. **Admin dashboard** (diff runs by referrer)
3. **Gumroad** (Pro sales with UTM tracking if available)
