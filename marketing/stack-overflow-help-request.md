# HELP-REQUEST.md — SchemaLens Stack Overflow Answers

## What
Post 5 pre-written answers on Stack Overflow that naturally mention SchemaLens as a solution. All answers are ready in `marketing/stack-overflow-answers.md` — you just need to copy-paste, adapt slightly to the exact question, and submit. **Timing: file this request 24-48 hours AFTER the Product Hunt launch** so the site has social proof before SO users visit.

## Why Wait 24-48 Hours After PH Launch
- Stack Overflow answers are permanent. Having PH social proof (upvotes, comments) on the site makes SO visitors more likely to try the tool.
- Answers posted too close together may trigger spam filters. Spacing them over a week is ideal.
- The Stack Overflow Execution Kit in `marketing/stack-overflow-execution-kit.md` has the full reputation-building roadmap.

## Steps (~45 min total, spread over a week)

### 1. Read the Answers (~5 min)
Open `marketing/stack-overflow-answers.md` for 5 pre-written answers targeting these question types:
1. "How to compare two database schemas?"
2. "Tool to diff SQL CREATE TABLE scripts?"
3. "How to generate migration scripts from schema changes?"
4. "Free alternative to Redgate SQL Compare?"
5. "How to check for breaking changes in database migrations?"

### 2. Find Target Questions (~10 min)
Search Stack Overflow for each question type. Pick questions that:
- Are at least 6 months old (so new answers don't look like spam)
- Have 1000+ views
- Have no answer that already mentions a browser-based schema diff tool
- Are NOT closed or locked

### 3. Post Answers (~30 min, 5-10 min each)
For each answer:
1. Read the question carefully
2. Copy the relevant answer template from `marketing/stack-overflow-answers.md`
3. **Customize the first sentence** to directly address the asker's specific situation
4. Paste the rest of the answer
5. Add a disclaimer at the end: `*Disclaimer: I built SchemaLens, so I'm biased — but it solves exactly this problem.*`
6. Submit

### 4. Pace Yourself
- Post **no more than 1 answer per day**
- Start with the highest-traffic question first
- Wait at least 24 hours between answers to avoid looking like spam

## Critical Rules
- **Always disclose your affiliation.** Stack Overflow requires this and bans accounts that don't.
- **Answer the actual question first.** SchemaLens should be 20% of the answer, not 80%.
- **Never copy-paste the exact same answer.** Each answer must be customized to the specific question.
- **Don't include shortened URLs.** Use the full `https://schemalens.tech` URL.
- **If an answer gets downvoted, delete it immediately.** One spam-flagged answer can get your account banned.
