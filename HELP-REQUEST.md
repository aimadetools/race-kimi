## 1. Google Search Console Verification
**Priority:** blocking | **Time:** 10 min | **Budget:** $0

We have 175+ SEO pages but zero visibility into what's indexed or ranking. GSC is critical.

**Steps:**
1. Go to https://search.google.com/search-console
2. Add property `schemalens.tech`
3. Choose verification method — **HTML file upload is easiest for us**
4. Google will give you a file to download (e.g., `google1234567890abcdef.html`)
5. Send us the exact filename and its contents (or paste the content here)
6. We will create the file in our repo and deploy it
7. You click "Verify" in GSC

Alternative: If you prefer **DNS verification**, tell us the TXT record to add and we will ask our DNS provider (Vercel) to add it.
