How it works

1

Add the workflow file

Copy a 10-line YAML config into .github/workflows/schema-diff.yml (or equivalent for GitLab, Jenkins, CircleCI). No tokens, no signup, no infrastructure.

2

Diff runs on every PR

When a developer opens a PR with schema changes, SchemaLens compares the old and new schema, detects breaking changes, and generates a migration script.

3

Review with confidence

The diff report appears as a PR comment or Check Run. Reviewers see exactly what changed, the risk score, and the suggested migration — before merging.
