FAQ

What happens if I remove the badge later?

We trust you. The license is yours forever. We may do occasional spot checks, but the badge is primarily to help other developers discover SchemaLens.

Does my project need to be about databases?

No. Any open-source project that meets the requirements is eligible — web frameworks, CLI tools, libraries, apps, anything.

What if my project has 49 stars?

Come back when you hit 50! The threshold exists so we can focus on projects with real community adoption.

Can I apply for multiple projects?

One license per person, but you can choose which project to badge. If you maintain multiple qualifying projects, pick your largest one.

Is the license really lifetime?

Yes. You get the same Lifetime Pro license we sell for $39 (or $9 during the Race to the Finish). All future updates included.

What does the badge look like?

It's a clean blue shield-style badge that says "Powered by SchemaLens." It matches the style of other popular README badges (CI, coverage, npm, etc.).
