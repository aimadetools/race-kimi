Frequently asked questions

Is my data really not uploaded anywhere?

Correct. LogDrop uses the FileReader API and Web Workers to parse files entirely inside your browser. Disconnect WiFi and it still works. We don't have a server that receives logs — we don't even have a server for parsing.

What file formats are supported?

JSON (structured logs), logfmt (key=value pairs), CSV, and plain text. Pro adds multiline stack trace parsing (Java, Python, Go, Ruby, Node.js patterns).

How does team sharing work without a backend?

We encode your filtered view (search terms, filters, but not the raw log data) into a URL hash. When a teammate opens the link, LogDrop prompts them to drop the same log file locally, then reapplies your filters automatically.

Can I use this for compliance audits?

Yes. Because no data leaves your machine, LogDrop is inherently SOC 2 and GDPR friendly. Our sanitized export feature automatically redacts emails, IPs, tokens and UUIDs for incident reports.

Is there an annual discount?

Yes. Pro annual is $180/year (2 months free). Team annual is $490/year.

What happens when I cancel?

You keep Free features forever. Pro features remain active until the end of your billing period. No data is ever deleted because we never stored it.
